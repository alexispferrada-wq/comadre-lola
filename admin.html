📖 Manual Oficial de Administración

Guía de procedimientos, uso del sistema y buenas prácticas para el equipo de La Comadre Lola.

📄 Descargar PDF Oficial (A4) 🌐 Ver Versión Web

📅 1. Gestión de Reservas

Revisa diariamente las solicitudes pendientes. Confirma llamando o enviando mensaje de WhatsApp al cliente. Si no asiste o cancela, actualiza el estado a "Cancelada" para liberar cupo.

🍽️ 2. Actualización de Carta

Entra a la pestaña Editor Web (CMS) ➔ Carta para modificar precios, agregar nuevos platos o actualizar fotos. Las fotos se comprimen en milisegundos automáticamente.

🎤 3. Cartelera de Shows

Actualiza semanalmente los eventos en Editor Web (CMS) ➔ Eventos con el flyer, fecha, hora y el enlace directo a FilaCero o WhatsApp para compra de entradas.

🚀 4. Publicación en Vivo

Cada vez que modifiques textos, fotos o precios, haz clic en el botón superior "🚀 Publicar en vivo" para que los cambios se reflejen de inmediato en toda la red.
